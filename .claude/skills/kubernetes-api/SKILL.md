# Kubernetes API

## Patching replicas (`pkg/scaler/executor.go`)

Always use strategic merge patch — never replace the entire Deployment spec:

```go
func (e *Executor) Execute(ctx context.Context, spec Spec, decision ScaleDecision) error {
    patch := []byte(fmt.Sprintf(`{"spec":{"replicas":%d}}`, decision.TargetReplicas))
    deploy := &appsv1.Deployment{}
    deploy.Name = spec.TargetDeployment
    deploy.Namespace = spec.Namespace
    return e.client.Patch(ctx, deploy, client.RawPatch(types.MergePatchType, patch))
}
```

## KEDA ScaledObject (`pkg/scaler/keda.go`)

When `spec.scaler.type: keda`, create or update a `ScaledObject` instead of patching replicas directly:

```go
scaledObject := &kedav1alpha1.ScaledObject{
    ObjectMeta: metav1.ObjectMeta{
        Name:      spec.TargetDeployment + "-agentic",
        Namespace: spec.Namespace,
    },
    Spec: kedav1alpha1.ScaledObjectSpec{
        ScaleTargetRef: &kedav1alpha1.ScaleTarget{Name: spec.TargetDeployment},
        MinReplicaCount: &spec.MinReplicas,
        MaxReplicaCount: &spec.MaxReplicas,
    },
}
```

## RBAC (`config/rbac/role.yaml`)

Generated by `controller-gen` from `+kubebuilder:rbac` markers in the controller:

```go
//+kubebuilder:rbac:groups=scaling.autoscaler.io,resources=agenticautoscalers,verbs=get;list;watch;create;update;patch;delete
//+kubebuilder:rbac:groups=scaling.autoscaler.io,resources=agenticautoscalers/status,verbs=get;update;patch
//+kubebuilder:rbac:groups=apps,resources=deployments,verbs=get;list;watch;update;patch
//+kubebuilder:rbac:groups=autoscaling,resources=horizontalpodautoscalers,verbs=get;list;watch
//+kubebuilder:rbac:groups=keda.sh,resources=scaledobjects,verbs=get;list;watch;create;update;patch;delete
```

Note: HPA access is `get;list;watch` only — never `update;patch;delete`.

## Status update pattern

Always use `r.Status().Update()`, not `r.Update()`, for status-only changes.
Never set status fields in the same call as spec fields:

```go
// After a scale action:
patch := client.MergeFrom(aa.DeepCopy())
aa.Status.LastDecisionReason = decision.Reason
aa.Status.CurrentReplicas = decision.TargetReplicas
aa.Status.LastScaleTime = decision.Timestamp
if err := r.Status().Patch(ctx, &aa, patch); err != nil {
    return ctrl.Result{}, fmt.Errorf("status update: %w", err)
}
```

## Useful kubectl commands during development

```bash
# Install CRDs
kubectl apply -f config/crd/bases/

# Watch operator logs
kubectl logs -n agentic-autoscaler-system deploy/agentic-autoscaler-controller-manager -f

# Inspect an AgenticAutoscaler status
kubectl get agenticautoscaler payment-service-autoscaler -n production -o yaml

# Check scale decisions (in status)
kubectl get agenticautoscaler -A -o jsonpath='{range .items[*]}{.metadata.name}: {.status.lastDecisionReason}{"\n"}{end}'
```
